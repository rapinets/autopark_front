# SPEC-006 — Керування допусками

Статус: Реалізовано для перевірки. Залежності: 003–005, API assignments. Користувач призначає водію доступні маршрути та скасовує допуски.

## Обсяг

Розширити блок допусків у #/drivers/:id. Отримати повний каталог маршрутів та пари допусків водія. Доступні варіанти = routes мінус assigned route_id. Форма активна лише після успішного завантаження обох джерел.
POST /assignments: {driver_id, route_id}. Після 201 перечитати допуски, оновити список, select та лічильник; призначений маршрут зникає з вибору.
DELETE /assignments/{driver_id}/{route_id}: діалог називає маршрут і водія. Після 204 маршрут повертається у вибір; водій і маршрут залишаються.
Порожні стани: немає створених маршрутів → посилання «Створити маршрут»; усі призначені → повідомлення; немає допусків → пояснення й доступна форма, якщо є маршрути. Помилка читання не дорівнює порожньому списку.

## Дизайн

На desktop список і компактна картка форми поряд, на mobile послідовно. Варіант select показує «номер — назва». Кнопка «Допустити до маршруту»; у рядку допуску — посилання на картку маршруту та «Скасувати допуск». Лічильник використовує правило множини 003.

## Задачі

- [x] Обчислено доступні маршрути за ID, не за назвами.
- [x] Реалізовано POST, підтвердження DELETE і синхронізацію читань.
- [x] Реалізовано обробку 404/409, блокування повтору та перечитування допусків.
- [ ] Реальні порожні/повні каталоги та конкурентні зміни перевірені частково на mock-даних; реальні POST/DELETE не виконувалися.

## Критерії приймання

- S006-AC-01: призначені маршрути не можна вибрати; неправильне/порожнє значення не надсилається.
- S006-AC-02: після 201 список, форма та N узгоджені; повторний клік не дублює запит.
- S006-AC-03: якщо інший запит уже створив допуск, 409 показано й список оновлено; відсутній водій/маршрут → 404 без уявного успіху.
- S006-AC-04: скасування діалогу не виконує DELETE; 204 видаляє лише допуск; 404 показує detail та актуалізує список.
- S006-AC-05: немає маршрутів / усі призначені / помилка каталогу — три різні стани; помилка не відкриває порожню активну форму.
- S006-AC-06: N=0,1,2,11,21,111 має правильну форму слова; весь блок працює на 360 px із клавіатури.

Поза обсягом: загальний список усіх допусків і окрема картка допуску — для них немає потреби в погодженому UI.
