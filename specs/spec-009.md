# SPEC-009 — Адаптивність, приймання й документація

Статус: Частково виконано — очікується тестове MySQL-середовище та фінальні скріншоти. Залежності: 001–008, тестове середовище з реальним MySQL. Мета: відтворюваний запуск і підтверджені основні сценарії.

## Обсяг

Фінальна перевірка дизайну, доступності, інтеграції та README. Нова функціональність не додається. Проблеми попередніх ітерацій виправляються з повторною перевіркою відповідних AC.

## Наскрізний сценарій

На окремому тестовому наборі: створити перевізника → автобус → маршрут → водія → відкрити картки → змінити водія → додати допуск → скасувати допуск → додати знову → видалити водія → перевірити відсутність його допусків у БД/API та наявність самого маршруту → перевірити головну.
Каскад перевіряється фактично в MySQL, а не лише зникненням DOM. Не використовувати робочі записи для руйнівних сценаріїв.

## Дизайн і доступність

Перевірити кожен екран та його loading/empty/error на 360, 768, 1440 px і при масштабі 200%. Без обрізаних форм/діалогів. Клавіатура проходить навігацію, форми, пагінацію та підтвердження; focus видимий і не губиться після видалення. Перевірити контраст, labels, reduced-motion, перенесення довгих значень.

## Документація

README фронтенду має містити: стек і структуру; передумови; точні команди запуску обраним HTTP-сервером; налаштування API_BASE_URL; приклад origin і CORS; навігаційні маршрути; порядок тестового наповнення; запуск перевірок; рішення щодо статистики; відомі обмеження.
Не включати паролі БД, приватні токени, твердження про непроведені тести. Зазначити версію/дату OpenAPI, на якій перевірено інтеграцію.

## Критерії приймання

- S009-AC-01: наскрізний сценарій завершений на реальному API; створені дані зберігаються після повторного відкриття.
- S009-AC-02: видалення тестового водія прибирає його допуски з MySQL; маршрут зберігається; невідомий водій дає 404.
- S009-AC-03: індекси відхиляють дублікати, API повертає погоджені 409; відсутній перевізник/маршрут/водій дає потрібну помилку.
- S009-AC-04: усі екрани й діалоги доступні на 360 px та при масштабі 200%; немає горизонтальної прокрутки всієї сторінки або прихованих дій.
- S009-AC-05: основний сценарій проходиться лише клавіатурою; немає виконання введеного HTML.
- S009-AC-06: інша людина може запустити фронтенд за README без усних пояснень; конфігурація не містить секретів.
- S009-AC-07: немає відкритих критичних критеріїв, console errors чи непідтверджених позначок «готово»; обмеження явно зазначені.
