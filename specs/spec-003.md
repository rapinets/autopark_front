# SPEC-003 — Картки окремих сутностей

Статус: Реалізовано для перевірки. Залежності: 002, GET деталей і допусків. Користувач переходить зі списку до зрозумілої детальної картки.

## Обсяг / маршрути

- #/companies/:id → GET /companies/{id}: назва, телефон, ID як другорядне значення.
- #/buses/:id → GET /buses/{id}: номер, модель, місця, перевізник із посиланням на його картку.
- #/routes/:id → GET /routes/{id}: номер, назва, відстань.
- #/drivers/:id → GET /drivers/{id}: ПІБ, телефон, посвідчення, перевізник із посиланням.
- У картці водія GET /drivers/{id}/routes та GET /routes/ для зіставлення route_id → номер/назва/відстань; це read-only список допусків.

Список і картка — окремі запити; пряме відкриття картки не вимагає попереднього відвідування списку. Невалідний ID не відправляти як довільний фрагмент URL. Unknown ID: not-found та повернення до списку.
Кнопка «До списку» відновлює попередні параметри водіїв, якщо вони відомі; при прямому вході відкриває початкову сторінку. Не залежати лише від history.back(), яке може вивести з застосунку.

## Дизайн

Breadcrumbs, заголовок сутності, другорядний тип/ID, картки «Основні дані» та «Перевізник». На desktop дві колонки, на mobile одна. Немає вигаданих статусів «активний», рейтингу чи фото.
Картка водія має окремий блок «Допуски до маршрутів». Лічильник: «Допущений до N маршруту/маршрутів». Форма «маршруту» при N%10=1 і N%100≠11; інакше «маршрутів». Якщо список не завантажився, N невідоме, не 0.
Дані водія, допуски та каталог мають незалежні стани. Якщо route_id не знайдено в каталозі, показати ID та повідомлення про недоступні деталі; не приховувати сам допуск.

## Критерії приймання

- S003-AC-01: кожна картка показує відповідний ID і поля з API; пряме відкриття та refresh працюють.
- S003-AC-02: 404 має зрозумілий стан і вихід до списку; мережева помилка має повтор.
- S003-AC-03: помилка каталогу/допусків не приховує успішно отримані дані водія; невідомий лічильник не показує 0.
- S003-AC-04: правильні тексти для N=0,1,2,5,11,21,111; допуски належать саме поточному водію.
- S003-AC-05: повернення до водіїв зберігає пошук/сторінку; 360 px, клавіатура й довгі тексти працюють.

Поза обсягом: зміни даних і допусків. Готовність: read-only перегляд усіх основних сутностей та допусків завершено.
