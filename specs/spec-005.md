# SPEC-005 — Редагування й видалення водія

Статус: Реалізовано для перевірки. Залежності: 004, PUT/DELETE водія. Користувач змінює дані водія або видаляє запис із розумінням наслідків.

## Обсяг

Редагування: #/drivers/:id/edit, GET деталей + GET перевізників, заповнена форма з 004. До завершення читання збереження недоступне. PUT містить усі full_name, phone, license_number, company_id; поля id/company_name не надсилати.
Після 200 перейти до картки й актуалізувати дані. У списку повторно застосовується серверний порядок: змінений ПІБ може перемістити запис на іншу сторінку.
Видалення доступне зі списку та картки. Діалог: «Видалити водія «ПІБ»? Усі його допуски до маршрутів також буде видалено. Цю дію неможливо скасувати». Кнопки «Скасувати», «Видалити».
Після підтвердження один DELETE /drivers/{id}, не цикл видалення допусків. 204 → актуалізація списку, вихід із видаленої картки. Якщо сторінка спорожніла й offset>0, перейти назад до непорожньої сторінки або offset=0.

## Дизайн

Той самий шаблон форми; заголовок «Редагування водія», primary «Зберегти зміни». Небезпечна дія в окремій зоні/меню, не поруч із primary без відступу. Діалог адаптивний, фокус спочатку на безпечній дії, Escape скасовує до надсилання. Після успіху видалений елемент не отримує фокус — фокус переходить на заголовок списку.

## Задачі

- [x] Повторно використано форму й валідатори.
- [x] Реалізовано оновлення, 404/409/422 та збереження введення.
- [x] Реалізовано доступне підтвердження, 204 і повернення до списку.
- [ ] Повне відновлення сторінки після видалення перевірено в коді; реальний edge-набір потребує тестових даних.

## Критерії приймання

- S005-AC-01: після GET форма заповнена; PUT передає всі потрібні поля; успішна картка показує нові значення.
- S005-AC-02: 404 може стосуватися водія або перевізника — UI показує detail без вгадування; 409/422 зберігають введення.
- S005-AC-03: скасування діалогу не виконує DELETE; підтвердження виконує один DELETE; 204 не парситься як JSON.
- S005-AC-04: після видалення останнього рядка сторінки відновлюється попередня; після видалення з картки користувач бачить список.
- S005-AC-05: при 404 видалення показати повідомлення й перечитати список; за мережевого збою не показувати непідтверджений успіх.
- S005-AC-06: клавіатура й focus діалогу працюють на 360 px; немає кнопок редагування/видалення інших сутностей.

Каскад BR-S1 — залежність бекенду. Візуальне зникнення водія не доводить видалення допусків у MySQL; наскрізна перевірка в 009.
